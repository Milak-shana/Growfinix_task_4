# 🔗 Student Task Management App – Interactive Prototyping & Usability Testing

## 📌 Internship Task

This project was created as part of my **UI/UX Design Internship at Growfinix Technology**.

The objective of Task 4 was to create an interactive prototype for the Student Task Management App and evaluate the usability of the designed user flows.

## 🎯 Project Goal

The main goal of this task was to connect the existing high-fidelity application screens into a logical and interactive user experience.

The project focused on:

- Creating clickable navigation between screens
- Testing important user flows
- Evaluating navigation clarity
- Checking the ease of task creation
- Testing task management and completion
- Identifying usability improvements

## 📱 Interactive Prototype

The existing high-fidelity screens were connected to create an interactive prototype.

### Main Prototype Flow

**Dashboard → Task Details → Edit Task / Mark as Completed**

### Task Creation Flow

**Dashboard → Add New Task → Enter Details → Save Task → Dashboard**

### Task Completion Flow

**Task Details → Mark as Completed → Task Completed → Dashboard**

### Progress Flow

**Bottom Navigation → Progress Overview**

The prototype was designed to provide clear and simple navigation between the main features of the application.

## 🧪 Usability Testing

A usability testing plan was prepared to evaluate the overall user experience.

### Testing Objectives

- Evaluate navigation clarity
- Test the ease of creating a task
- Check whether users can find task details
- Test task completion
- Evaluate progress tracking

### Sample User Tasks

1. Create a new academic task.
2. Find an existing task.
3. View task details.
4. Edit task information.
5. Mark a task as completed.
6. Check overall progress.

## 👥 User Feedback

Sample user feedback was organized to identify positive aspects and potential usability issues.

### Positive Feedback

- Easy and understandable navigation
- Clean and simple interface
- Straightforward task creation process
- Clear task management flow

### Improvement Opportunities

- Clearer task filtering
- More noticeable priority indicators
- More flexible reminder options
- Better visibility of progress information

## 🔍 Usability Findings

The usability analysis focused on the following areas:

### Navigation

Most users were able to understand the main navigation and move between screens easily.

### Task Creation

Users found the task creation form simple and easy to complete.

### Task Management

Users could view, edit, and update tasks without major difficulty.

### Areas for Improvement

The analysis identified opportunities to improve:

- Task filtering
- Priority visibility
- Reminder customization
- Progress tracking

## 🤖 AI-Assisted Analysis

ChatGPT/Gemini AI was used to help:

- Organize user feedback
- Identify recurring usability issues
- Group similar feedback
- Analyze usability patterns
- Suggest potential improvements

### AI Analysis Workflow

**User Testing → Collect Feedback → AI Analysis → Identify Recurring Issues → Suggested Improvements**

## 💡 Proposed Improvements

Based on the usability findings, the following improvements were suggested:

- Add clearer task filtering options
- Make priority indicators more noticeable
- Provide flexible reminder settings
- Improve the visibility of progress statistics

## 🛠️ Tools Used

- Figma Prototyping
- FigJam
- Google Forms
- ChatGPT/Gemini AI

## 🚀 Key Learning

This task helped me understand that UI/UX design does not end after creating visually appealing screens.

Interactive prototyping and usability testing are important for understanding how users actually navigate and interact with a product. Testing user flows and analyzing feedback helps identify usability problems and improve the overall user experience.
